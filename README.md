# When a shared batch composition changes a dispatch decision

Technical report by Vedant Thaker, Independent Researcher, Jeffersonville, Indiana. Correspondence: vedant.thaker1602@gmail.com.

A pick station can receive an unknown mix of orders in two different ways. Tickets drawn from one randomly shuffled batch have the same marginal type probability at both stations. Separate queues can have different mixtures. For a fixed dispatch plan with affine receipt utility, the difference between the two worst-case scores is determined by cancellation of slopes across stations. A ten-ticket example gives different optimal actions under the two assumptions. The calculation identifies the operational fact a dispatcher must establish before aggregating risk.
